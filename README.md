# 🎬 Satisfying Animations — Facebook Short Film Generator

A **100% free** p5.js project for creating viral satisfying animation videos for Facebook monetization.

## 🎯 6 Animation Scenes

| # | Scene | Description |
|---|-------|-------------|
| 1 | **Color Sorting Balls** | Colorful balls falling into matching color buckets |
| 2 | **Spiral Satisfaction** | Mesmerizing spiral dot patterns rotating |
| 3 | **Liquid Fill** | Shapes filling up with liquid + wave animation |
| 4 | **Particle Vortex** | 600 particles orbiting in a glowing vortex |
| 5 | **Pendulum Wave** | 24 pendulums creating beautiful wave patterns |
| 6 | **Gravity Balls** | Balls bouncing down zigzag platforms |

## ▶️ How to Run

### Option 1: VS Code Live Server
1. Install "Live Server" extension in VS Code
2. Right-click `index.html` → "Open with Live Server"

### Option 2: Python HTTP Server
```bash
cd project2
python -m http.server 8000
```
Then open `http://localhost:8000`

### Option 3: Direct Browser
Just double-click `index.html` (sound may not work without a server)

## 📹 Recording for Facebook

### Setup OBS Studio (Free)
1. Download [OBS Studio](https://obsproject.com/) (free)
2. Settings → Video → Base Resolution: **1080x1920** (vertical)
3. Settings → Video → Output Resolution: **1080x1920**
4. Settings → Video → FPS: **60**
5. Settings → Output → Recording Format: **mp4**

### Recording Workflow
1. Open the animation in your browser
2. Press `H` to hide controls
3. Start OBS recording
4. Let the animation run for 1-3 minutes
5. Stop recording
6. Upload to Facebook

### Tips for Maximum Views
- **Video length**: 3+ minutes for mid-roll ads
- **Post daily**: 1-2 videos per day
- **Add captions**: "Which color is your favorite?" to boost comments
- **Use trending hashtags**: #satisfying #oddlysatisfying #asmr
- **Post at peak hours**: 7-9 PM local time of your target audience

## 💰 Monetization Path

Sounds include pops, clicks, swooshes, and deep tones that sync with the animations.
